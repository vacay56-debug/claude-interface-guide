# Claude 新人教學（消防署救護科）

兩份單頁 HTML 教學，涵蓋從介面設定到實際產出的完整流程。無相依套件，直接用瀏覽器開啟即可。

| 文件 | 內容 |
|---|---|
| [`index.html`](index.html) | **① 介面操作與設定** — 左側欄、帳號選單、Settings 各分頁、方案與付費、新人首日設定清單 |
| [`usage.html`](usage.html) | **② 實際使用篇** — 對話框與模型選擇、提示詞四要素與業務範例庫、來回修正、Projects／Skills／Artifacts 實作、產出 Word／PPT／Excel、限制與查證、七日練習清單 |

兩份文件上方可互相切換，共用 `assets/style.css`，皆支援深色模式與行動裝置；檢核清單的勾選狀態存於瀏覽器本機。
