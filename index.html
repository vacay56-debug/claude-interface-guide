Claude 介面操作與設定教學

本教學依畫面由左至右、由外而內的操作順序編排：先認識左側欄，再進入帳號選單與設定頁，最後說明方案管理。每一節左側為介面示意，黃色編號對應右側說明。

1

左側欄（Sidebar）

左側欄是所有工作的起點，負責開新對話、切換專案、查看產出物與排程任務。

  4. 4

    Chat（對話圖示）為一般對話、文件撰寫與研究；Code（</>）切換至 Claude Code，用於程式開發與本機檔案自動化。一般公文、簡報作業使用 Chat 即可。

3

設定頁（Settings）

設定頁左側分為三群組：Settings（帳號與使用設定）、Desktop app（桌面應用程式）、Customize（擴充能力）。以下依畫面由上而下說明。

3.1 Preferences（偏好設定）

區塊項目選項與說明建議
Appearance 外觀Theme 主題三個圖示依序為：跟隨系統／淺色／深色辦公室長時間使用選「跟隨系統」
Chat font 字型預設 Anthropic Serif（襯線體），可自下拉選單改用其他字型閱讀大量中文時可改為無襯線字型，較清晰
Motion 動態System：跟隨系統；Reduced：減少回覆串流與介面動畫對動畫敏感或電腦效能較低時選 Reduced
Voice 語音Language 語言語音模式辨識與朗讀語言，目前為 English主要以中文口述者，改為中文選項
Style 聲音語音模式的聲音風格（如 Buttery）依個人偏好試聽選擇
Speed 語速朗讀速度，預設 Normal維持預設即可
Notifications 通知Response completionsClaude 完成回覆時發送通知，適合長時間任務建議開啟，執行研究或大量文件產製時可先處理其他公務

Preferences 頁面下方另有「個人偏好」欄位（Profile／user preferences），可寫入職稱、業務範圍與輸出格式要求（如「一律繁體中文」、「公文採三段式」），Claude 每次對話都會參考。此欄位修改後僅適用於新對話。

3.2 Account、Privacy、Billing、Usage

項目用途重點操作
Account 帳號姓名、稱呼、登入裝置管理設定 Claude 稱呼您的名字；不明裝置可於此登出
Privacy 隱私資料使用與匯出確認「是否允許對話用於改善模型」的設定；可匯出帳號資料
Billing 帳務方案、付款方式、發票經 App Store 訂閱者，方案變更須在 iOS App 內辦理（見第 4 章）
Usage 用量目前使用額度與重置時間大量作業前先確認剩餘額度，避免任務中斷

公務資料提醒

個人帳號屬商用雲端服務。涉及機密、個人資料（如病患資料、身分證字號）或未公開之採購底價、評選資料，請勿上傳，並依機關資通安全規定辦理。

3.3 Capabilities、Memory、Design systems

項目用途建議
Capabilities 功能開關各項能力：網路搜尋、程式執行與檔案建立（產製 Word、Excel、PPT）、Artifacts 等建議全部開啟；檔案建立為產製公文、簡報檔的必要功能
Memory 記憶「由對話產生記憶」及「搜尋與參照過往對話」開啟後 Claude 可延續跨對話的業務脈絡；可隨時檢視、修改或刪除記憶內容。不需延續的對話可使用無痕（incognito）模式
Design systems 設計系統設定簡報、視覺設計預設使用的配色、字型與版型建立機關識別樣式後設為預設，簡報風格即可統一

3.4 Claude Code、Cowork、Claude in Chrome

項目說明適用情境
Claude Code程式開發代理工具的相關設定建置 HTML 訓練工具、批次處理檔案
Cowork桌面版知識工作代理，可操作本機檔案與已連接的應用程式；Dispatch 手機配對亦由此管理整理資料夾內多份文件、跨檔案彙整報告
Claude in Chrome瀏覽器代理擴充功能的權限與網站設定協助查詢網頁資料、填寫表單（送出前均須您確認）

3.5 Desktop app（桌面應用程式）

項目說明
General 一般開機自動啟動、快捷鍵、視窗行為等桌面版基本設定
Extensions 擴充安裝桌面擴充元件，讓 Claude 使用本機應用程式或工具
Developer 開發者本機 MCP 伺服器設定檔與除錯紀錄；一般使用者無須調整

3.6 Customize（擴充能力）

Customize
▤Skills1
⊞Connectors2
⚲Plugins3
  1. 1
    Skills 技能

    可重複使用的工作指引（SKILL.md）。上傳自建技能後，Claude 會在相符任務自動套用，例如公文起草、預算說明書、採購文件、政策簡報。建議將科內範本與格式規範做成技能，確保產出一致。

  2. 2
    Connectors 連接器

    授權 Claude 存取外部服務，例如 Gmail、Google 日曆、Google 雲端硬碟、Gamma。授權時請確認權限範圍；寄信、刪除等動作 Claude 會先徵求同意。

  3. 3
    Plugins 外掛

    整合技能、指令與連接器的套件，一次安裝即具備特定業務流程能力。

  1. 1
    QR Code：至 iOS App 變更方案

    您目前是透過 App Store 訂閱，升級、降級或取消都必須在 iPhone 的 Claude App 內辦理，網頁版無法直接變更。以手機掃描 QR Code 即可開啟 App。

  2. 2
    Buy usage credits：購買額外用量

    不變更方案，另以信用卡購買額外用量額度，原 App Store 訂閱維持不變。適用於短期大量作業（如研討會前集中產製資料）。

  3. 3
    Back to Claude

    返回主畫面。

取消 App Store 訂閱路徑：iPhone「設定」→ 點選 Apple ID 名稱 →「訂閱項目」→ Claude。
